User Journey Flow — Compliance Officer

How a compliance officer interacts with the GLDB system from login to remediation

🔑 Login
Officer opens localhost:3000, enters credentials (email + password). System authenticates and loads dashboard with unread alert count.
Action: Enter email → Click "Sign In"
🔔 Review Alerts
Dashboard shows summary cards (Total / Unread / Immediate / Review / Info). Officer scans severity badges, department assignments, and how long ago each alert was created.
Action: Filter by severity → Scan unread alerts
Clicks "View Change" on Critical alert
📋 Investigate Regulatory Change
Changes & Impact tab shows the specific change. Officer sees: regulation title, impact level (Critical with ⚠️ PENALTY badge), affected areas, compliance deadline, and change summary.
Action: Read summary → Click "View Diff"
🔍 Compare Old vs New Version
Side-by-side comparison panel opens. Left = Previous Version, Right = Current Version. Structured diff shows ➕ Added / ➖ Removed / ✏️ Modified sections. Officer understands exactly what changed.
Action: Read diff → Understand scope of change
Checks Task column
❓ Was a task auto-created?
For Critical/High changes, the Dispatcher agent should have auto-created a task. Officer checks the "Task" column for status.
✅ Yes — Auto-task exists
👁️ View Task
Click "View" → navigates to Tasks tab. Task shows linked regulatory changes (📋 badge).
Action: Click "View" button
❌ No — Medium/Low only
➕ Create Task Manually
Click "+ Create" → pre-fills task form with regulation title + department.
Action: Click "+ Create" → Submit
✅ Manage Tasks
Tasks tab shows all remediation work. Each task has clickable badges: 🔗 linked gaps, 📋 linked changes. Officer updates status as work progresses: Pending → In Progress → Completed.
Action: Update status dropdown → "In Progress"
Navigates to Gaps tab (via 🔗 badge)
⚠️ Review Compliance Gaps
Gaps tab shows AI-identified gaps with type classification (Missing Procedure / Insufficient Detail / Missing Control / etc.), severity, and linked task status. Progress bar shows remediation %.
Action: Filter by type/severity → Review gap details
📜 Policy Governance
Policies tab shows 15 internal policies as cards. Officer clicks "View Procedures" to see step-by-step actions. "AI Proposals" sub-tab shows pending AI-drafted policy changes with procedures + reasoning.
Action: Review proposal → Click "✅ Accept & Apply" or "❌ Reject"
Accepting auto-versions old policy
— Remediation Complete —
🎯 Mark Task Completed
Officer marks task as "Completed". System automatically updates ALL linked gaps to "Remediated" status. Compliance score improves in Reports tab.
Action: Status dropdown → "Completed"
📊 Generate Reports
Reports tab: 4 sub-tabs (Regulatory Changes, Gap Analysis, Tasks & Remediation, Compliance Posture). Officer reviews compliance score %, policy heatmap, and gap resolution trends. Prints report for management.
Action: Review charts → Click "🖨️ Print Report"
📑 Verify Audit Trail
Audit Trail shows every action (AI + Human). Officer switches to "Response Chain" view, selects a regulation, and sees the complete evidence trail: Scraped → Assessed → Gaps → Tasks → Remediated. Printable for MAS inspection.
Action: Select regulation → View full chain → Print audit report
📧 Send Email Digest
Officer presses "Send Test Alert Email" button. ONE summary email is sent to Gmail with all Critical/High alerts consolidated in a formatted table. Used for stakeholder communication.
Action: Click "📧 Send Test Alert Email"
♻️ Cycle Repeats
System continues monitoring 24/7. Next automated scan in 2 weeks (or manual "Run Scraper" button). Any new regulatory changes restart the journey from the top — alerts appear, tasks are created, gaps are identified.
